# Zombie Survival RPG Prototype (Godot 4.x)

Стартовый прототип 3D zombie-survival с RPG-элементами и **open world** подходом (одна большая заранее подготовленная карта).

## Что уже есть
- Передвижение персонажа: ходьба, бег, прыжок.
- Камера от 3-го лица с управлением мышью.
- Базовая атака ближнего боя (ЛКМ) с кулдауном.
- Зомби преследуют игрока и наносят контактный урон (базовый, быстрый, танк).
- Простая RPG-база: здоровье, сила, стамина, XP, уровень и расчет урона.
- Базовый инвентарь ресурсов: `medkit` и `scrap`.
- Использование аптечки (`F`) с лечением от текущего запаса.
- Крафт аптечек у верстака (`E`) за `scrap`.
- Спавн зомби вокруг игрока и рядом с POI.
- HUD с HP/Stamina/XP/Level в реальном времени.
- Волновая система с ростом лимита врагов и интенсивности спавна.

## Open world foundation
- Одна большая карта `1200 x 1200` как базовый ландшафт.
- Набор заранее размещённых POI (`Supermarket`, `Hospital`, `PoliceStation`, `IndustrialZone`).
- Простейшие блоки зданий как заполнитель для будущей авторской геометрии.
- Центральная логика спавна учитывает POI, что упрощает расширение карты и событий.


## План разработки
- Подробный пошаговый план: `ROADMAP.md`


## Режим камеры
- Игра работает в режиме **от третьего лица (3rd person)**.
- Камера закреплена на персонаже через `SpringArm3D`, чтобы сохранять вид на героя и уменьшать клиппинг вблизи объектов.
- Мышь управляет обзором (yaw + pitch), `Esc` освобождает курсор, ЛКМ возвращает захват курсора.

## Управление
- `WASD` — движение
- `Shift` — бег (тратит стамину)
- `Space` — прыжок
- `ЛКМ` — удар (тратит стамину)
- `F` — использовать аптечку
- `E` — крафт аптечки у верстака
- `Esc` — освободить курсор

## Структура
- `scenes/Main.tscn` — большая open world сцена
- `scenes/Player.tscn` — игрок
- `scenes/Zombie.tscn` — базовый зомби
- `scenes/FastZombie.tscn` — быстрый тип зомби
- `scenes/TankZombie.tscn` — танк-тип зомби
- `scripts/player.gd` — логика игрока
- `scripts/zombie.gd` — логика зомби
- `scripts/main.gd` — логика open world спавна + волны
- `scenes/Workbench.tscn` — верстак для крафта
- `scripts/workbench.gd` — триггер взаимодействия с верстаком
- `scenes/Pickup.tscn` — подбираемые предметы мира
- `scripts/pickup.gd` — логика подбора предметов
- `scripts/hud.gd` — обновление HUD (HP/Stamina/XP/Level/Inventory)

Откройте проект в Godot 4.x и запустите сцену `Main.tscn`.
