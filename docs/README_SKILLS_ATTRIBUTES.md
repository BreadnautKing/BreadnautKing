# Skills & Attributes Design (RPG Layer)

## 1. Цель системы
Система навыков и атрибутов должна:
- давать ощутимый рост силы без one-shot дисбаланса;
- поддерживать разные стили игры (ближний бой, стрелок, выживание, контроль);
- работать в связке с открытым миром (день/ночь, радиация, ресурсы, подводные зоны).

## 2. Базовые атрибуты персонажа
### 2.1 Primary Attributes
1. **Strength**
   - увеличивает melee урон;
   - немного повышает шанс stagger у врагов.
2. **Agility**
   - повышает скорость смены оружия/уклонения;
   - слегка уменьшает расход stamina на действия.
3. **Vitality**
   - повышает максимум HP;
   - ускоряет пассивную регенерацию вне боя.
4. **Fortitude**
   - повышает базовую Armor и сопротивление входящему урону.
5. **Tech**
   - снижает стоимость крафта/ремонта;
   - усиливает эффективность гаджетов/ловушек.
6. **Survival**
   - повышает добычу редких ресурсов;
   - улучшает сопротивление радиации и контроль кислорода.

### 2.2 Secondary Stats (вычисляемые)
- Max HP
- Max Stamina
- Armor
- Radiation Resistance
- Oxygen Capacity
- Crit Chance / Crit Damage
- Stamina Regen
- Craft Efficiency
- Loot Quality Chance

## 3. Формулы роста (черновик)
- `MaxHP = BaseHP + Vitality * 12`
- `MaxStamina = BaseStamina + Agility * 5 + Survival * 3`
- `MeleeBonus = Strength * 0.04`
- `Armor = BaseArmor + Fortitude * 2`
- `RadiationResist = BaseRad + Survival * 1.5 + Fortitude * 0.5`
- `OxygenCapacity = BaseOxygen + Survival * 4`
- `CraftCostModifier = 1.0 - min(Tech * 0.01, 0.35)`

Ограничения:
- мягкие капы, чтобы исключить «сломанные» билды;
- high-end прирост должен замедляться (diminishing returns).

## 4. Навыки (Skill Trees)
## 4.1 Структура
- 4 ветки, у каждой по 3 тира (Novice / Advanced / Master):
  1. **Hunter (Бой)**
  2. **Warden (Защита/выживание)**
  3. **Scavenger (Лут/крафт)**
  4. **Tactician (Контроль/тактика)**

- В каждом тире 4–6 нод.
- Для открытия следующего тира нужно вложить минимум X очков в текущий.

## 4.2 Примеры навыков
### Hunter
- +% урон ближнего боя
- +% урон в голову/слабые точки
- «Кровавый импульс»: частичный возврат stamina за добивание

### Warden
- -% входящий урон ночью
- +% сопротивление bleed/infection
- «Последний шанс»: краткий щит при падении HP ниже порога

### Scavenger
- +% шанс редкого лута
- -% стоимость крафта аптечек/патронов
- «Полевой ремонт»: ускоренный ремонт в safe zone

### Tactician
- +длительность контроля (stun/slow)
- +эффективность ловушек
- «Рывок охотника»: короткий тактический дэш с кд

## 5. Очки развития
- За каждый уровень: **+2 Attribute Points**
- Каждые 2 уровня: **+1 Skill Point**
- За ключевые квесты/боссов: бонусные Skill Points

## 6. Респек (перераспределение)
- Бесплатный респек до 10 уровня.
- После 10 уровня: респек за редкий ресурс + soft currency.
- Ограничение: не чаще 1 раза за игровой день (анти-абуз).

## 7. Балансные принципы
- Нет обязательной «единственно правильной» ветки.
- Любой билд должен быть играбельным на Normal.
- Hard требует более точной синергии статов/навыков.
- Запрещаем one-shot паттерны на обычных врагах вне ультраредких условий.

## 8. Alpha scope
Минимальный скоуп для альфы:
- 6 primary attributes;
- 4 skill trees по 1–2 тира;
- 16–24 активных/пассивных навыка;
- UI: экран атрибутов + экран навыков + подсветка рекомендованных синергий.

## 9. Связь с core-loop
- Исследование даёт ресурсы и XP.
- Бой даёт XP и открывает доступ к навыкам.
- Крафт усиливается через Tech/Scavenger.
- Ночные/опасные зоны проверяют сборку по Survival/Warden.

Это делает RPG-слой не «декором», а центральной частью выживания.
