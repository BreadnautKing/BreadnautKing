# Economy & Balance Design

## 1. Ресурсные слои
- Базовые: scrap, medkit components, ammo materials
- Продвинутые: tech parts, bio-gel, alloy
- Редкие: mutant core, reactor cell, relic circuit

## 2. Source / Sink модель (что приходит и куда тратится)
- **Scrap**
  - Source: лут POI, разбор предметов
  - Sink: крафт медкитов/ремонт/базовые апгрейды
- **Ammo materials**
  - Source: склады, военные POI
  - Sink: крафт боезапаса
- **Rare cores**
  - Source: элиты, мини-боссы, лаборатории
  - Sink: high-tier крафт и апгрейды

## 3. Темп прогрессии (цель)
- ~10–15 минут на 1 уровень в ранней игре.
- ~10–15 минут на осмысленный лутинг одного POI.
- ~60 минут на исследование и закрытие большого района.

## 4. Редкости
- Common
- Uncommon
- Rare
- Epic
- Legend
- Mythic
- Super-Duper

## 5. Крафт альфы
- Несколько образцов всех классов (melee/ranged базового уровня)
- Вспомогательные предметы (medkit, бустеры)
- Один комплект брони (голова/торс/руки/ноги)

## 6. Апгрейд-лестница
На каждый предмет:
- C → B → A → S (4 ранга улучшений)

## 7. TTK и сложность
- Нельзя допускать one-shot меты по обычным врагам для любого оружия без условий.
- Бой должен оставаться динамичным и требовать позиционирования.
- Средняя смертность: 1–3 раза за 2–3 часа игры на Normal.

## 8. Difficulty modes
- Easy
- Normal (референс)
- Hard

Различия: агро, входящий урон, ресурсы, штрафы за смерть.
