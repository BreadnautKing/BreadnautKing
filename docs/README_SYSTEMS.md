# Systems Design — Combat, Enemies, Stats

## 1. Базовые статы игрока
- HP
- Stamina
- Armor
- Radiation Resistance
- Oxygen (под водой)
- Strength
- Agility
- Vitality

## 2. Типы оружия (дорожная карта)
- Melee: нож, мачете, топор, молот
- Ranged (этапно): пистолет, ПП, дробовик, штурмовая винтовка, marksman
- Heavy/utility позже: огнемёт, гранаты, ловушки

## 3. Формула урона (черновик)
`FinalDamage = (WeaponDamage * SkillCoeff + FlatBonus) * CritCoeff * ZoneCoeff * TimeOfDayCoeff * DifficultyCoeff - ArmorMitigation`

Где:
- `ArmorMitigation = Armor / (Armor + 120)` (мягкое насыщение)
- Ночью враги получают `TimeOfDayCoeff = 1.08–1.15`
- Крит зависит от оружия и перков

## 4. Статусы/эффекты
- **Bleed:** периодический урон
- **Fracture:** замедление
- **Infection:** снижает максимум stamina до лечения
- **Stun:** короткий контроль
- **Radiation Burn:** накапливается в заражённых зонах

## 5. Враги на альфу
1. Обычный
2. Быстрый
3. Танк
4. Скрытный (рывки из укрытий)
5. Мини-босс
6. Босс

## 6. Поведение врагов
- Днём: менее агрессивны, медленнее реагируют.
- Ночью: умеренный бафф статов и агро.
- В группе: поведение "стадо" — давление фронтом + попытки окружения.

## 7. Спавн (без волн)
- Открытый мир, контекстный спавн по зоне/времени суток/World Pulse.
- Волновой режим только для отдельных активностей (опционально как POI-event), не как основной режим мира.

## 8. Смерть и восстановление прогресса
- При смерти игрок дропает "эхо-рюкзак" (Echo Cache) с ресурсами и частью предметов.
- Игрок респавнится в safe zone.
- Если успел вернуться и забрать Echo Cache — полностью восстанавливает инвентарь.
- Если не успел до таймера/повторной смерти — часть лута конвертируется в "потерянное" (штраф).

## 9. Сложность по прогрессии
- Враги масштабируются по уровню игрока (мягко, без резких скачков).
- Мини-боссы/боссы получают отдельные фазы и уязвимости.
- Цель: за 2–3 часа 1–3 смерти в среднем при нормальной игре.
