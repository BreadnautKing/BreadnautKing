# LiveOps & Release Plan

## 1. Этапы
### Alpha
- Проверка core-loop, боевки, базовой экономики
- 10 POI, 6 архетипов врагов, базовый крафт

### Beta
- Расширение квестов, баланс-итерации, стабильность
- Первые сезонные ивенты

### 1.0
- Полный контентный и UX проход
- Подготовка долгосрочного roadmap на 12+ месяцев

## 2. Патчи
- Hotfix: по критическим багам максимально быстро
- Плановые обновления: по возможности регулярно, на основе загрузки и фидбека

## 3. Сбор фидбека
- Основной канал: Discord
- Шаблон репорта: шаги, скрин/видео, ожидаемое/фактическое поведение

## 4. Bug triage
- Critical: блокер прогрессии/краш/потеря сейва
- High: серьёзный дисбаланс/эксплойт
- Medium: заметные UX и системные баги
- Low: косметика/редкие проблемы

## 5. Публичный roadmap
- Да, с горизонтом 5–10 лет (крупные вехи + короткие итерации)

## 6. Метрики качества
- Crash-free sessions
- Средняя длительность сессии
- Completion rate ключевых активностей
- Win/loss ratio по сложностям

## 7. Go/No-Go Alpha -> Beta
Переход только если:
1. Core-loop статус = READY
2. Нет Critical багов
3. Retention D1 в целевом диапазоне
4. Экономика не ломается эксплойтами
5. Игроки проходят стартовый путь без блокеров
