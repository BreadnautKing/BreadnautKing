# Production & Technical Constraints

## 1. Команда
- Текущий формат: solo-dev
- Codex используется как production assistant (документация, прототипирование, итерации)

## 2. Техническая цель по железу
Ориентир:
- Диапазон ПК 2010–2020 годов
- Фокус на доступность для бюджетных сборок

## 3. Визуальный пайплайн
- Стиль: Stylized Midpoly
- Цель: уникальный, "весёлый" и читаемый визуал

## 4. Ассет-стратегия
- На старте допустимо использовать store assets для 3D/UI/SFX/music
- Постепенная замена ключевых элементов на уникальные

## 5. Сохранения
- База: локальные сейвы на ПК
- Цель: добавить Steam Cloud при технической готовности

## 6. Локализация/моддинг
- Локализация: нужна
- Моддинг: после стабилизации основных систем

## 7. Основные риски
1. Scope creep (слишком быстрый рост объёма)
2. Баланс экономики при F2P-модели
3. Ограничения solo-production по контенту
4. Производительность на старом железе

## 8. Антирисковые меры
- Жёсткие этапы (alpha gate -> beta gate)
- Контентные батчи с приоритетом core-loop
- Регулярный техдолг-спринт
