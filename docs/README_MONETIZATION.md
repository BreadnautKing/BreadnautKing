# Monetization Design (Fair F2P)

## 1. Модель
Целевая модель:
- **F2P + Battle Pass + Premium DLC**

## 2. Принципы
1. No Pay-to-Win.
2. Всё, что влияет на силу, должно добываться игровым путём.
3. Донат ускоряет косметику/комфорт, но не ломает баланс.

## 3. Что монетизируем
- Косметика (скины персонажа/оружия/эффекты)
- Battle Pass с косметическим контентом и soft currency
- Premium DLC (новые зоны/сюжетные главы/боссы)

## 4. Что НЕ монетизируем
- Прямые бусты урона/броня "только за деньги"
- Эксклюзивные paywalled мета-статы

## 5. Базовая цена/региональность
- Референс для RU рынка: около 500 ₽ для отдельных premium пакетов/DLC
- Для внешнего рынка: региональная адаптация цены

## 6. Каналы дистрибуции
Приоритетно там, где есть аудитория и адекватные условия для RU-разработчика:
- ПК-площадки (основной фокус)
- Поэтапный выход, начиная с наиболее реалистичных каналов

## 7. KPI (для наблюдения)
- D1 / D7 / D30 retention
- ARPPU
- Conversion to first purchase
- Battle Pass completion rate
- Доля игроков, получающих ключевые награды без доната (fairness metric)
