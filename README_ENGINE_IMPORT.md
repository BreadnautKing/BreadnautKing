# Как выгрузить из GitHub и открыть проект в Godot 4.x

Этот гайд — отдельная инструкция по загрузке проекта из GitHub и запуску в движке.

## 1) Что нужно установить заранее
- **Godot Engine 4.x** (желательно 4.2+)
- **Git**

> Важно: проект создан под Godot 4.x (`project.godot` уже в репозитории).

---

## 2) Как скачать проект из GitHub

### Вариант A: через Git (рекомендуется)
1. Открой терминал.
2. Выполни:

```bash
git clone <URL_ТВОЕГО_РЕПО>
cd BreadnautKing
```

### Вариант B: ZIP-архив
1. На странице репозитория нажми **Code → Download ZIP**.
2. Распакуй архив в удобную папку.
3. Убедись, что внутри есть файл `project.godot`.

---

## 3) Как открыть проект в Godot
1. Запусти **Godot 4.x**.
2. В Project Manager нажми **Import**.
3. Выбери файл:
   - `.../BreadnautKing/project.godot`
4. Нажми **Import & Edit**.

После этого проект появится в списке проектов Godot.

---

## 4) Как запустить игру
- В редакторе нажми **F5** (Run Project),
  или кнопку **▶ Run** вверху.
- Главная сцена уже задана: `res://scenes/Main.tscn`.

---

## 5) Если Godot ругается на версию
Если открыл проект в более старой версии (например, 3.x), будут ошибки.

Что делать:
- Установи Godot **4.x**,
- снова импортируй через `project.godot`.

---

## 6) Как обновлять проект из GitHub
На будущее, когда будут новые коммиты:

```bash
cd BreadnautKing
git pull
```

Потом просто снова открывай проект в Godot (или нажми Reload в редакторе).

---

## 7) Частые проблемы

### Проект не импортируется
- Проверь, что выбираешь именно `project.godot`, а не папку/сцену.

### Нет текстур/ресурсов
- Убедись, что скачал весь репозиторий целиком.

### Не запускается
- Проверь консоль Godot на первую красную ошибку и пришли её — по ней проще всего дебажить.

---

## 8) Мини-чек после первого запуска
- Открылась сцена мира.
- Игрок двигается (`WASD`).
- Камера от 3-го лица управляется мышью.
- Работают атака/аптечка/крафт (`ЛКМ` / `F` / `E`).

Если всё это работает — проект корректно загружен в движок.
